# 한녕 — 한·영 자동 전환 입력기

**한녕**은 ‘한영키 이제는 안녕’의 줄인 말로 Mac에서 두벌식 키를 그대로 치면 문맥에 따라 한글·영어·혼합어로 자동 확정하는 InputMethodKit 입력기입니다. 판별은 앱에 들어 있는 로컬 모델이 이 Mac 안에서 합니다.

## 설치

[Releases](https://github.com/gityeop/hannyeong/releases/latest)에서 `Hannyeong-<버전>-arm64.pkg`를 내려받아 엽니다. 설치 프로그램은 Apple 공증을 받았고, 관리자 암호 없이 이 사용자 계정의 `~/Library/Input Methods`에 설치합니다.

- **요구 사항:** Apple Silicon Mac, macOS 15.0 이상. 실제 설치·입력은 macOS 27.2에서 확인했습니다.
- 설치 후 메뉴바 입력 메뉴에서 **한녕**을 선택합니다. 처음 쓸 때 모델을 읽느라 잠시 준비 시간이 걸립니다.
- 메뉴에 한녕이 없으면 **로그아웃 후 다시 로그인**하세요. 최근 macOS는 새 입력 소스를 로그아웃 전까지 목록에 반영하지 않는 경우가 있습니다([Apple 포럼](https://developer.apple.com/forums/thread/775526)). 그래도 없으면 시스템 설정 → 키보드 → 텍스트 입력 → 입력 소스 → 편집 → **+** → 한국어 → **한녕**을 추가합니다.

업데이트는 새 pkg를 같은 방법으로 설치하면 됩니다.

## 사용법

기본 입력은 두벌식 한글입니다. `dkssud`를 치면 Space 전부터 `안녕`이 미확정 문자열로 보이고, Space·Return·숫자·문장부호에서 영문 유지 여부를 판별해 확정합니다. 영어 키도 입력 중에는 두벌식 한글로 보이다가 영어로 판별되면 영어로 바뀝니다.

- **오른쪽 ⌘ 한 번:** 입력 중이거나 방금 확정된 단어를 한글↔영어 반대로 바꿉니다. 누를 때마다 한글과 영어 입력 모드가 번갈아 전환됩니다.
- **오른쪽 ⌘ 빠르게 두 번:** 방금 변환한 단어의 교정 후보창을 엽니다. **1 또는 2**를 누르거나 후보를 클릭하면 글자를 바꾸고 문맥과 함께 기억합니다. ↑↓로 이동하고 Return으로 확정하며 Esc로 취소합니다.
- 단어 뒤에 `.`·`?` 같은 기호와 공백을 입력한 뒤에도 교정할 수 있으며, 기호·공백은 그대로 보존합니다.
- 같은 키 입력을 모든 문맥에서 같은 결과로 고정하려면 설정 → 저장된 교정에서 그 교정의 기억 방식을 ‘항상’으로 바꿉니다.
- **Esc:** 타이핑 중이던 단어를 영어로 반환합니다.


설정 창은 입력 메뉴에서 열거나 다음 명령으로 엽니다.

```sh
open "$HOME/Library/Input Methods/Hannyeong.app" --args --settings
```

## 개인정보

- **판별은 로컬 안에서만 합니다.** 입력기는 네트워크 요청을 보내지 않습니다.
- **교정과 개인 학습은 로컬에만 저장합니다.** 교정 기록과 개인 보정값은 `~/Library/Application Support/Hannyeong/`에 저장하고 어디에도 전송하지 않습니다. 이 폴더를 지우면 모두 초기화됩니다.
- **진단 로그에는 입력 내용을 남기지 않습니다.**
- **사용 데이터를 수집하지 않습니다.** 분석 도구나 원격 수집 기능이 없습니다.
