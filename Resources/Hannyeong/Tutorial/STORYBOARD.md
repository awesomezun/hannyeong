# 사용법

## Frame 1
status: outline
src: index.html#choose
0–8초. 입력기 메뉴에서 한녕을 선택한다. 카드가 나타나고 선택 행과 체크가 강조된다.

## Frame 2
status: outline
src: index.html#type
8–17초. 키 예시 dkssud hello와 Space를 보여준 뒤 결과 안녕 hello를 보여준다. 순서대로 글자와 키가 나타난다.

## Frame 3
status: outline

17–26초. F8을 눌러 후보를 고르고 선택이 다음 입력에 반영된다는 것을 보여준다. F6 원문·F7 한글은 작은 보조 안내로만 둔다.
