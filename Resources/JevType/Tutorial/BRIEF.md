# 한녕 사용법

설정 화면의 긴 사용법을 별도의 짧은 애니메이션으로 옮긴다. 사용자 요청에 따라 Hyperframes로 제작하고 현재 Mac 앱의 ‘사용법 보기’에서 재생한다. 한국어로 입력 소스 선택, Space/Enter 자동 변환, F8 교정을 설명한다. 실제 앱의 동작과 기존 ㅎ 아이콘을 기준으로 하며 유료 서비스나 외부 업로드를 사용하지 않는다. 앱에 MP4를 포함한다.

제작 선택: 무음, 26초, 1280×800. 사용자에게 영상 제작과 앱 적용이 이미 요청된 작업이다.
